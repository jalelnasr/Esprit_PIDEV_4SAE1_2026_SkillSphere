📱 WORKFLOW UTILISATEUR FINAL

CANDIDAT (Frontend Angular)
        │
        ├─→ Voit les offres d'emploi
        │
        ├─→ Clique sur une offre
        │
        ├─→ Remplit le formulaire de candidature
        │
        └─→ Clique "Submit"
                │
                ▼
   APPLICATION CRÉÉE (Status: PENDING)
                │
                ▼
        RH VOIT LA CANDIDATURE
                │
                ├─→ Accède à /admin/b2b/jobs/3
                │
                ├─→ Voit la liste des candidatures
                │
                ├─→ Clique "✅ Accept"
                │
                ├─→ Modal s'ouvre
                │   ├─ Email candidat (pré-rempli)
                │   ├─ Message personnalisé (optionnel)
                │   └─ Boutons: "Accept" / "Reject"
                │
                ├─→ RH clique "Accept & Send Email"
                │
                └─→ BACKEND TRAITE
                        │
                        ├─→ Mettre à jour Application.status = ACCEPTED
                        │
                        ├─→ Appeler EmailService
                        │
                        └─→ Envoyer email au candidat via SMTP
                                    │
                                    ▼
                        CANDIDAT REÇOIT EMAIL 📧

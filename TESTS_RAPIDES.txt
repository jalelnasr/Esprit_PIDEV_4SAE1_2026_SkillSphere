TESTS RAPIDES - Gestion des Candidatures
==========================================

1. Démarrer le backend:
   cd B2BModule
   mvn spring-boot:run

2. Démarrer le frontend:
   cd PI_4eme-Template/PI_4eme-Template/Platforme
   npm install
   ng serve

3. Accéder à l'application:
   http://localhost:4200/admin/b2b/applications

4. Tester:
   - Liste des candidatures avec filtres
   - Accepter/Refuser une candidature
   - Voir le détail d'une candidature
   - Envoi d'emails

COMPOSANTS CRÉÉS:
✅ application-list.component (Liste + Filtres + Modal)
✅ application-detail.component (Détails + Timeline)
✅ Routes ajoutées dans b2b.routes.ts
